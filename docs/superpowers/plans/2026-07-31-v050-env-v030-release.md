# 通用版 v0.5.0 与环境版 v0.3.0 发布实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 将已经完成并通过测试的环境目录 v4.0 与 CNKI 来源类别检索实现，封装为通用版 `0.5.0` 和环境版 `0.3.0`，完成文档、版本、安装、CI、确定性构建、GitHub Release 及发布后共存安装验证。

**Architecture:** 本计划是三部分实施工作的发布阶段，只消费前置计划生成的 v4.0 目录产物和两版 CNKI 运行代码，不重新实现目录生成或检索算法。两版继续独立维护 Skill、MCPB、运行环境和安装配置；环境版在 Skill ZIP 中附带离线复算脚本，在 Skill ZIP 与 MCPB 中镜像目录及来源快照。GitHub Actions 分别验证两版，并只从 Ubuntu Python 3.11 作业上传各自的规范发布产物。

**Tech Stack:** Python 3.11—3.14、pytest、FastMCP、Playwright、uv、ruff、mypy、PowerShell、POSIX Shell、GitHub Actions、GitHub CLI、ZIP、SHA-256。

## Global Constraints

- 实施基线是分支 `codex/v4-catalog-source-category-design` 的设计提交 `b6f9dd0`；其中已批准设计 `docs/superpowers/specs/2026-07-31-environment-catalog-v4-cnki-source-category-design.md` 基于 `main@76651999980bc3f5c9bd283f90002a1efda97851`。
- 必须先完成环境目录生成计划和两版 CNKI 算法计划，并确认其定向测试为 GREEN；本计划不得重新实现目录匹配、TI/SU/KY/TKA 放宽、来源类别筛选或跨组去重算法。
- 通用版从 `0.4.2` 升至 `0.5.0`；环境版从 `0.2.0` 升至 `0.3.0`。
- MCP 服务及工具名不得改变：`cnki-search` 暴露 `cnki_search`、`cnki_professional_search`；`cnki-search-env` 暴露 `cnki_search_env`、`cnki_professional_search_env`。
- 通用专业检索 `group` 只允许 `chinese_top_journals`、`cssci`；环境专业检索 `group` 只允许 `chinese_environment_top`、`other_formally_recognized_chinese`、`environment_cssci`、`pku_core`。
- `source_category` 是策略内部字段，不得成为任一 MCP 工具的公开输入参数。
- 环境目录固定为 v4.0、3764 种唯一期刊、十二级；发布阶段不得改变期刊层级、数量、`journal_id` 或证据判断。
- 环境 Skill 与 MCPB 中的 11 件目录、机器数据、来源清单、审计摘要和来源快照必须逐字节一致；活动发布包不得继续包含 v3.0 目录。
- `top-journal-search-lists-env/.gitattributes` 负责规范产物 LF 和七份来源快照 `-text`；仓库根 `.gitignore` 只为 `docs/audits/environment_journal_match_audit_v4.0.jsonl` 增加精确跟踪例外，不放宽其他 JSONL 忽略规则。
- `scripts/environment_catalog_v4.py` 与 `scripts/generate_environment_catalog_v4.py` 只进入环境 Skill ZIP，不进入环境 MCPB；完整审计 JSONL 只留在仓库，不进入任何发布包。
- MCPB manifest schema 继续使用 `0.4`；Python 下限继续为 `>=3.11`；依赖边界继续为 `mcp>=1,<2`、`playwright>=1.45,<2`。
- CI 不访问 CNKI、WebVPN 或 ai4scholar；任何真实登录、验证码和站点请求都不属于发布 CI。
- Ubuntu 继续测试 Python 3.11、3.12、3.13、3.14；Windows 与 macOS 继续测试 Python 3.11；三平台安装器继续拒绝 Python 3.10。
- 安装器继续使用事务式复制、失败恢复和最多 3 份备份。通用版只能写入 `top-journal-search-lists`、`cnki-search`、`runtimes/cnki-search`；环境版只能写入 `top-journal-search-lists-env`、`cnki-search-env`、`runtimes/cnki-search-env`。
- 不修改两版安装器的复制协议；安装内容由各自 `scripts/build_release.py --copy-skill` 白名单决定。
- ZIP 使用固定时间戳 `(1980, 1, 1, 0, 0, 0)`、确定性排序和文件白名单；不得包含缓存、Cookie、浏览器配置、登录状态、下载内容、检索结果、本机绝对路径或仓库完整审计 JSONL。
- 通用版和环境版测试必须在两个独立 Python 进程中运行，避免顶层同名 `catalog_lookup` 相互污染。
- 历史设计、计划、交接和基线评估记录既有事实，不追溯改写。
- 正式产物只取自 `release-canonical-ubuntu-py3.11` 和 `release-environment-ubuntu-py3.11`；不得复用旧 Release 附件或旧哈希。
- 合并后标签固定为 `v0.5.0` 与 `top-journal-search-lists-env-v0.3.0`；两个同名 `checksums.sha256` 必须放入各自独立的 Release。
