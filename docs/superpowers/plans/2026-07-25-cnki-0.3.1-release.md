# CNKI Skill 0.3.1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 将 CNKI Skill 版本统一提升到 `0.3.1`，固定 Ubuntu Python 3.11 为唯一正式发布构建环境，并从通过 CI 的 `main` 提交发布 `v0.3.1`。

**Architecture:** 版本仍由两个分发布局的 `cnki_search.__version__`、MCPB manifest、pyproject 和 uv.lock 共同声明，并由契约测试检查一致性。CI 保留完整跨平台验证，但只有 Ubuntu 3.11 上传正式附件；发布命令只消费合并后 `main` 的该附件。

**Tech Stack:** Python 3.11 至 3.14、pytest、ruff、mypy、GitHub Actions、GitHub CLI、MCPB、ZIP。

## Global Constraints

- 产品版本必须统一为 `0.3.1`。
- Python 最低版本保持 `3.11`。
- `v0.3.0` 标签、Release 和附件不得修改。
- 只有 Ubuntu Python 3.11 上传正式附件。
- 不修改 CNKI 检索、登录、下载、限流和浏览器会话行为。
- 标签必须指向通过合并后 `main` CI 的精确提交。
