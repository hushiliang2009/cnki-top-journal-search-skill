# CNKI 新版入口统一设计

设计日期：2026-07-22  
状态：已确认  
适用范围：CNKI 检索 Skill、MCP、跨客户端封装、安装包及其与 `top-journal-search-lists` 的集成

## 一、最终决定

CNKI 高级检索和专业检索只使用新版入口：

- 直连入口：`https://kns.cnki.net/kns8s/AdvSearch`
- 河海大学 WebVPN 入口：`https://webvpn.hhu.edu.cn/https/77726476706e69737468656265737421fbf952d2243e635930068cb8/kns8s/AdvSearch`

项目不保留其他检索入口，不提供回退模式，不接受入口版本参数，也不维护其他页面适配器。验证码、403、429、权限不足、会话失效或页面结构变化只会使当前任务停止，不会切换到其他入口。

此前与其他入口有关的设计和实施计划已从有效文档中移除。发生文档冲突时，以本设计为准。

## 二、设计依据

### 1. 实机证据

河海大学 WebVPN 下的新版页面已经形成可复核的运行证据：

- 用户手工登录后能够进入 CNKI；
- 专业检索返回 20 条结果；
- 结果中存在《数字化转型、企业创新与新质生产力》；
- 详情链接能够进入 WebVPN 代理下的 `/kcms2/article/abstract` 页面。

命中数量会随数据库更新变化，因此测试验证页面结构、字段解析和目标记录，不把 20 作为永久固定断言。

### 2. 压缩包复核

`cnki-search-skill-main.zip` 使用 `kns8s` 内部 HTTP 接口，不支持 WebVPN URL 改写。其分层、结构化错误、缓存和文件校验思路可供独立实现参考，但不得复制没有明确许可证的源码，也不得采用内部接口直连、Cookie 注入、并发详情请求或自动重试策略。

`scansci-pdf-master.zip` 不含 CNKI 检索代码。其持久化浏览器 profile、代理轮换和跨 IP 会话复制不符合已批准的临时会话边界，不纳入本项目。可借鉴内容仅限可见浏览器中的官方按钮下载、单实例调度和下载文件校验等一般方法。

## 三、目标与非目标

### 1. 目标

- 高级检索和专业检索统一采用新版页面合同；
- 同一套页面操作支持 CNKI 直连和河海大学 WebVPN；
- 使用可见浏览器页面和官方可见控件完成检索、详情查看与下载；
- 串行、低频运行，遇到验证、限流、权限或页面结构异常立即停止；
- Codex、Claude Code、Claude Desktop 调用同一实现；
- 与 `top-journal-search-lists` 共用结果目录、题录字段和期刊目录匹配能力；
- 通过测试先行、独立解压测试和实机验证证明可用性。

### 2. 非目标

- 不由程序构造或直接调用 `/kns8s/brief/grid`、`/dm8`、`download/order` 等内部 HTTP 接口；用户授权后点击官方可见下载按钮时，由页面正常触发的浏览器请求不在此限；
- 不自动处理验证码，不绕过访问控制，不切换代理或 IP；
- 不导出或持久化 Cookie、localStorage 和其他会话状态；
- 不读取 Chrome、Edge 或其他浏览器的用户数据目录；
- 不批量抓取超出已批准限额的页面或文件；
- 不导入 Sci-Hub、LibGen、Tor、FlareSolverr 等无关能力。

## 四、入口解析

入口解析只依据当前接入环境：

- 当前会话处于 `webvpn.hhu.edu.cn` 域时，打开固定的 WebVPN 新版入口；
- 当前会话处于 CNKI 源站时，打开固定的直连新版入口；
- 当前主机不属于上述允许范围时，停止并返回 `session_expired`；
- WebVPN URL 不写入易过期的 `wrdrecordvisit` 参数；
- URL 只能由固定允许列表生成，禁止接受任意主机并附带会话信息。

统一接口为：

```text
resolve_search_entry(access_mode) -> approved_new_url
```

`access_mode` 只允许 `direct` 或 `hhu_webvpn`。公开工具和配置中不得出现入口版本选项。

## 五、系统结构

### 1. 组件职责

- `EntryResolver`：生成固定允许列表内的直连或 WebVPN 新版 URL；
- `NewSearchPageProfile`：维护新版高级检索、专业检索、结果、详情和下载控件合同；
- `PageStateClassifier`：根据可见控件、遮罩、URL 和页面主体识别状态；
- `SearchRunner`：依据新版页面合同执行串行交互；
- `RateLimiter`：统一控制检索翻页、详情与下载间隔；
- `EvidenceWriter`：保存脱敏结果、运行状态、下载校验和错误证据。

所有选择器必须由真实新版页面证据支持。`li[name="gradeSearch"]`、`li[name="majorSearch"]` 等已有选择器只有在新版脱敏夹具和实机页面均验证成立后才能保留。

### 2. 会话模型

继续采用已经批准的临时可见浏览器上下文：

- 用户在可见浏览器中手工完成 WebVPN 登录；
- MCP 进程只在内存中持有当前会话；
- 不创建持久化用户数据目录；
- 不读取、复制或导出 Cookie、localStorage、Local State 和浏览器缓存；
- 不在 Codex、Claude Code 和 Claude Desktop 之间落盘共享登录态；
- 任务完成后关闭会话，释放浏览器和内存状态。

持久化 CNKI 专用 profile 不属于本设计。若以后需要采用，必须重新提交会话安全设计并单独获得批准。

### 3. 页面状态识别

状态识别优先检查实际可见元素，不得只搜索正文提示词：

- `ready`：URL、页面主体、检索控件和提交按钮符合新版页面合同；
- `login_required`：出现可见登录表单或 WebVPN 身份验证界面；
- `captcha`：验证码控件、验证遮罩或交互验证框实际可见；
- `rate_limited`：可见 429 或访问过于频繁提示；
- `forbidden`：可见 403 或拒绝访问提示；
- `permission_required`：详情或下载页显示权限不足；
- `session_expired`：会话失效或被重定向到登录页；
- `page_contract_changed`：关键控件缺失、结构不明或定位结果存在歧义。

无法可靠判断时按 `page_contract_changed` 停止。诊断工具必须返回真实会话状态，不能固定写为 `ready`。

## 六、检索、结果与下载流程

### 1. 标准流程

1. 检查直连或 WebVPN 会话状态；
2. 如需 WebVPN 登录，打开可见浏览器并等待用户手工完成；
3. 打开新版入口并验证新版页面合同；
4. 执行高级检索或专业检索；
5. 解析结果并展示编号、题名、作者、来源和年份等字段；
6. 根据任务要求打开有限数量的详情页或导出题录；
7. 只有通过下载授权门槛后，点击官方可见 PDF 或 CAJ 按钮；
8. 保存脱敏证据并关闭会话。

### 2. 高级检索

- 题名精确检索必须选择篇名字段，不能误写为主题；
- 只传入驱动明确支持且页面中实际存在的筛选项；
- 暂不支持的 `source_types` 等参数应在接口层拒绝并返回说明，不能传入底层；
- 提交前核对字段、匹配方式、关键词、年份和来源限制；
- 保存规范化查询、命中数和首屏结果的脱敏证据。

### 3. 专业检索

- 表达式原样显示或记录在运行证据中；
- 通过页面输入框和可见检索按钮提交；
- 结果解析以新版真实结果容器和稳定链接属性为准；
- 至少覆盖 `TI`、`SU`、`KY`、`AB` 等已确认字段表达式；
- 表达式非法时返回结构化错误，不自动改写用户含义。

### 4. 详情与题录

- 只打开当前结果页中的官方详情链接；
- WebVPN 环境保持在代理域内，不改写为绕过 WebVPN 的直连地址；
- 统一输出题名、作者、机构、来源、年份、摘要、关键词、DOI、CNKI 标识和详情 URL 等可获得字段；
- 与 `top-journal-search-lists` 合并时，只对期刊名称、ISSN 和目录层级进行匹配，不改变 CNKI 原始题录。

### 5. 下载授权门槛

下载前必须同时满足：

1. 已向用户展示编号结果；
2. 用户明确选择下载编号；
3. 用户确认具有相应访问权限；
4. 用户指定保存目录，或明确接受当前默认下载目录；
5. 页面存在官方可见 PDF 或 CAJ 下载控件。

上述条件满足后，每个文件都必须先等待 8 至 15 秒再点击下载按钮，包括任务中的首个文件或唯一文件。下载完成后校验文件头、文件大小和 SHA-256。若得到 HTML、登录页、验证页或未知格式，立即删除无效文件并停止。

## 七、限流与停止规则

所有浏览器操作串行执行。

| 操作 | 默认上限 | 间隔 |
|---|---:|---:|
| 检索结果翻页 | 默认 1 页，最多 3 页 | 4 至 7 秒 |
| 详情页 | 每次任务最多 10 篇 | 3 至 6 秒 |
| 下载 | 每次任务最多 5 篇 | 每次点击前 8 至 15 秒 |

遇到下列情形立即停止：验证码、403、429、登录失效、权限不足、页面合同变化、下载格式异常或用户要求停止。停止后返回状态、发生阶段、脱敏 URL 和建议的人工操作。程序不自动重试，不切换代理，也不切换检索入口。

## 八、测试先行设计

### 1. 脱敏夹具

从已登录的可见浏览器只采集新版高级检索、专业检索、结果页、详情页和下载控件所需结构。保存前清除输入值、检索历史、Cookie、localStorage、会话令牌、个人信息、WebVPN 动态参数及无关正文。

### 2. 单元测试

至少覆盖：

- 直连和 WebVPN 新版 URL 解析正确；
- 公开接口不存在入口版本参数；
- 项目中不存在其他检索入口常量、导航方法或页面合同；
- 验证码、403、429、权限不足、会话失效和页面合同变化立即停止；
- 篇名精确检索使用篇名字段；
- 不支持的筛选参数不会传入驱动；
- 专业检索表达式保持原意；
- WebVPN 结果和详情链接不脱离代理域；
- 下载授权条件缺少任一项时拒绝下载；
- 单篇、首个和连续下载均在每次点击前等待 8 至 15 秒；
- HTML 和未知下载文件会被清理并报告失败；
- 限流上限和停止规则生效。

### 3. 回归测试

- 专业检索实机证据的结果结构能够解析；
- 能准确识别《数字化转型、企业创新与新质生产力》；
- 能从结果进入 `/kcms2/article/abstract` 详情页；
- 结果字段不会混淆题名、主题和来源。

### 4. 集成与安装测试

- 主源码、Skill 资源和 MCPB 内置副本保持一致；
- 从全新临时目录独立解压 ZIP 后运行全部测试；
- 包内不包含浏览器 profile、`Local State`、Cookie 数据库、缓存和固定用户路径；
- 在 Codex、Claude Code 和 Claude Desktop 分别验证工具清单、启动、状态检查和关闭会话；
- 以真实新版页面完成一次高级检索、一次专业检索和一次详情读取；
- 仅在用户明确授权后验证一次官方文件下载。

## 九、文档、封装与目录集成

- `SKILL.md`、`README.md` 和 CNKI 参考文档只说明新版入口；
- 故障诊断区分登录问题、页面合同变化、限流、权限不足和下载格式异常；
- Codex Skill、Claude Code 和 Claude Desktop 只封装同一 MCP 实现；
- 客户端之间不共享落盘会话，只共享代码、静态资源和非敏感配置；
- CNKI 结果保持原始题录字段；
- 使用规范化期刊名、ISSN 和目录资源补充期刊层级；
- 输出区分 CNKI 原始字段与目录匹配字段；
- 未匹配期刊标记为未匹配，不推断其期刊等级；
- 打包使用相对路径，独立解压后仍可读取目录资源。

## 十、迁移要求

1. 将生产入口统一改为新版；
2. 删除其他入口常量、解析函数、导航分支、适配器和配置选项；
3. 删除针对其他页面合同的测试与夹具；
4. 依据新版实机证据重新验证并命名选择器；
5. 修复篇名被作为主题检索的问题；
6. 拒绝驱动未支持的 `source_types` 等参数；
7. 更新全部文档、示例、默认配置和安装包；
8. 对主源码、Skill 副本和 MCPB 副本执行一致性检查；
9. 完成测试和实机证据后再安装到三个客户端。

## 十一、验收标准

- 直连与河海大学 WebVPN 均能正确解析新版入口；
- 代码、测试、文档和包内不存在其他检索入口；
- 新版高级检索能以篇名精确检索目标论文；
- 新版专业检索能提交受支持的表达式并解析结果；
- 能识别目标论文并打开对应详情；
- 验证、403、429、权限不足、会话失效和页面结构异常均立即停止；
- 下载经过编号选择、权限确认和目录确认，并通过文件校验；
- 临时会话结束后不留下 Cookie、Local State 或浏览器 profile；
- 单元测试、回归测试、集成测试和独立解压测试全部通过；
- Codex、Claude Code、Claude Desktop 的安装与启动验证通过；
- `top-journal-search-lists` 目录匹配不覆盖 CNKI 原始题录；
- 设计、实现、安装包和运行证据保持一致。

## 十二、实施边界

下一步按测试失败、最小实现、测试通过和重构复核的顺序开发。实机登录、检索和下载仍保留人工确认节点。未经用户另行批准，不改变临时会话边界，不扩大请求数量，也不加入任何其他检索入口。
