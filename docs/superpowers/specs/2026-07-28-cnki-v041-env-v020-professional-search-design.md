# CNKI 通用版 v0.4.1 与环境版 v0.2.0 专业检索设计

日期：2026-07-28

适用仓库：`hushiliang2009/cnki-top-journal-search-skill`

基准提交：`7c858951e407da55980e69dced7c8c3edc1fe859`（v0.4.0）

## 1. 背景与问题

v0.4.0 已包含 WebVPN 人工值守模式所需的专业检索表达式、会话管理、页面驱动和 MCP 工具声明，但默认生产入口没有创建专业检索运行时。`CnkiMcpServer()` 仅在测试注入 `professional_factory` 时才能调用专业检索；正常启动的 MCP 服务即使设置了 `CNKI_WEBVPN_HOME`，仍会返回未启用的配置错误。

此外，页面驱动已经具备每页显示 50 条和设置 CSSCI 来源类别的能力，现有专业检索服务却只把表达式字符串交给执行器，无法向生产页面驱动传递分组对应的页面设置。测试使用伪执行器，未覆盖默认生产入口和页面设置之间的连接，因此没有发现这一缺陷。

本次工作先以 v0.4.1 修复通用版，再将修正后的结构移植到环境版 v0.2.0。两个 Skill 保持独立安装和独立运行。

## 2. 目标

### 2.1 通用版 v0.4.1

- 使正常启动的 MCP 服务能够按需创建 WebVPN 专业检索运行时。
- 使 `cnki_professional_search` 在生产路径中真正设置每页 50 条和必要的来源类别。
- 保留公开主题检索 `cnki_search(query, limit=20)` 的现有行为。
- 修复公开页面状态分类中已确认的安全问题，包括检索按钮兼容、提交后状态识别和临时无数据状态。

### 2.2 环境版 v0.2.0

- 保留 `cnki_search_env(query, limit=20)` 和环境领域十级期刊判级。
- 新增独立工具 `cnki_professional_search_env`。
- 仅支持环境领域中文顶级期刊和环境领域 CSSCI 两个专业检索分组。
- 沿用通用版修正后的运行时、会话管理、页面契约和异常分类，但不对通用版形成运行时依赖。

### 2.3 共同要求

- WebVPN 专业检索仅用于人工值守场景。
- 用户本人完成统一身份认证和可能出现的安全验证，程序不接触账号密码。
- 不自动破解验证，不切换代理，不导出 Cookie，不保存浏览器登录状态。
- 两个版本均须完成真实 WebVPN 端到端验证后才能发布。

## 3. 非目标

- 不恢复旧版知网入口。
- 不通过 WebVPN 下载论文。
- 不连接用户日常 Chrome 会话、CDP 端口或现有浏览器配置。
- 不提供无人值守、定时检索或批量抓取能力。
- 不开放任意专业检索表达式的 MCP 工具。
- 不扩大公开主题检索的 20 条上限。
- 不为环境版增加全部 SSCI、SCIE 或其他大规模外文期刊的 WebVPN 专业检索。
- 不修改或移动既有 v0.4.0、v0.3.1 和环境版 v0.1.0 标签及附件。

## 4. 总体架构

采用相同设计模式、各自完整实现的方式。两个 Skill 使用一致的接口边界和契约测试，但各自包含运行所需源码、目录、安装器和 MCPB，不互相导入 Python 包。

### 4.1 运行时工厂

专业检索新增默认生产运行时工厂。工厂负责：

1. 读取并校验本产品的 WebVPN 首页环境变量。
2. 启动可见 Playwright Chromium。
3. 创建非持久化浏览器上下文和页面。
4. 建立 WebVPN 会话、页面驱动、限速器、断点和专业检索服务。
5. 返回同时支持检索和异步关闭的运行时对象。

`CnkiMcpServer` 首次调用专业检索工具时按需创建运行时，后续调用在同一 MCP 服务进程中复用。测试仍可注入伪工厂，但默认生产构造不得依赖测试注入。

### 4.2 执行计划

以分组感知的执行计划替代只有表达式字符串的执行器参数。单个批次至少包含：

- 专业检索表达式；
- 批次编号和总批次数；
- 每页显示数量，固定为 50；
- 可选来源类别；
- 期刊范围和年度范围的摘要信息。

页面驱动收到执行计划后，填写并核验表达式，提交检索，等待明确结果状态；如需来源类别，先设置来源类别并等待结果稳定，再设置每页 50 条并等待结果表重新渲染，最后解析题录。

### 4.3 产品隔离

| 项目 | 通用版 | 环境版 |
|---|---|---|
| 版本 | 0.4.1 | 0.2.0 |
| MCP 服务名 | `cnki-search` | `cnki-search-env` |
| 公开工具 | `cnki_search` | `cnki_search_env` |
| 专业工具 | `cnki_professional_search` | `cnki_professional_search_env` |
| WebVPN 环境变量 | `CNKI_WEBVPN_HOME` | `CNKI_ENV_WEBVPN_HOME` |
| 专业检索分组 | `chinese_top_journals`、`cssci` | `chinese_environment_top`、`environment_cssci` |

安装器只修改本产品的 Skill 目录、运行时目录和 MCP 配置表。两个产品可以同时安装，不得覆盖对方的文件、配置或备份。

## 5. 检索范围与数据流

### 5.1 通用版

#### `chinese_top_journals`

- 读取综合期刊目录中的 13 种中文顶级期刊。
- 构造主题与期刊来源字段的精确专业检索表达式。
- 不设置 CSSCI 来源类别。
- 设置每页 50 条后解析第一页。

#### `cssci`

- 构造主题表达式，并按可选年度范围增加年度条件。
- 不再枚举数百种 CSSCI 期刊名称。
- 提交后在结果页设置 CSSCI 来源类别。该类别包含来源期刊和扩展版。
- 设置每页 50 条后解析第一页。

### 5.2 环境版

#### `chinese_environment_top`

- 从环境版目录读取 6 种中文环境顶级期刊。
- 构造主题与期刊来源字段的精确表达式。
- 不设置 CSSCI 来源类别。
- 设置每页 50 条后解析第一页。

#### `environment_cssci`

- 从环境版目录读取 241 种环境领域 CSSCI 期刊。
- 构造主题、期刊来源和可选年度条件。
- 按知网表达式长度上限动态分批，不把批次数写死。
- 每个批次均设置 CSSCI 来源类别，再设置每页 50 条。
- 分批既限定环境领域期刊，又核验结果属于 CSSCI 来源类别。

### 5.3 批次调度与结果整理

- 所有批次串行执行，不并发访问知网。
- 正常批次之间至少间隔 30 秒。
- 达到用户请求数量后停止尚未提交的批次。
- 以标准化篇名、期刊和发表年度组成去重键。
- 重复题录保留信息较完整的记录，不采用首次出现即永久保留的规则。
- 最终结果按期刊等级、发表年度和原始结果顺序稳定排序。
- 返回篇名、作者、期刊、发表年度、期刊等级、来源分组、完成情况和简短警告。

## 6. MCP 工具契约

### 6.1 通用版

```text
cnki_search(query, limit=20)

cnki_professional_search(
    topic,
    group="chinese_top_journals",
    limit=50,
    year_from=None,
    year_to=None
)
```

`group` 只允许 `chinese_top_journals` 和 `cssci`。专业检索 `limit` 为 1 至 50。

### 6.2 环境版

```text
cnki_search_env(query, limit=20)

cnki_professional_search_env(
    topic,
    group="chinese_environment_top",
    limit=50,
    year_from=None,
    year_to=None
)
```

`group` 只允许 `chinese_environment_top` 和 `environment_cssci`。专业检索 `limit` 为 1 至 50。

### 6.3 参数约束

- `topic` 必须包含非空白字符。
- 年度必须是合理的四位年份。
- 同时提供两个年度时，`year_from` 不得大于 `year_to`。
- 不满足 MCP schema 的输入使用 MCP 标准 `isError`。
- 通过 schema 的请求始终返回结构化结果，不输出 traceback。

## 7. 会话生命周期

### 7.1 登录

- 首次专业检索调用启动可见 Chromium 并打开配置的 WebVPN 知网首页。
- MCP 调用最多等待 600 秒，由用户在同一窗口内完成认证。
- 认证完成后，同一 MCP 进程复用内存会话。
- 服务重启、浏览器窗口关闭或会话失效后，用户必须重新登录。

### 7.2 浏览器状态

- 使用 `browser.new_context()` 创建非持久化浏览器上下文，不使用 `launch_persistent_context()` 和固定用户目录。
- 不再要求 `CNKI_WEBVPN_PROFILE`，环境版也不新增持久化 profile 配置。
- 不导出 `storage_state`，不复制 Cookie，不接入用户日常浏览器配置。
- 浏览器上下文禁止下载。

### 7.3 并发、取消与关闭

- 每个产品的专业检索运行时使用异步锁，浏览器操作严格串行。
- 客户端取消当前请求时，停止未提交批次并关闭当前页面。
- 关闭 MCP 服务时取消排队任务，不等待已放弃的任务自然结束。
- 运行时依次关闭页面、上下文、浏览器和 Playwright。
- 正常关闭、取消、超时和异常退出均清理临时目录。

## 8. 状态与异常处理

| 状态 | 含义 | 处理规则 |
|---|---|---|
| `success` | 已获得并解析题录 | 正常返回 |
| `partial` | 已有部分批次结果，后续批次未完成 | 返回已完成题录和停止原因 |
| `no_results` | 页面明确显示没有相关文献 | 不重试 |
| `no_data_retry_later` | 页面显示暂无数据、请稍后重试 | 不得误报为无结果 |
| `login_required` | 登录超时、窗口关闭或认证失效 | 提示重新登录 |
| `challenge_detected` | 出现人工安全验证且未完成 | 停止或等待人工处理 |
| `page_contract_changed` | 页面控件或结果结构不符合契约 | 不重试 |
| `configuration_error` | 地址、浏览器或运行时配置错误 | 不重试 |
| `network_error` | 瞬时网络错误 | 最多重试一次 |
| `forbidden` | 站点明确拒绝访问 | 停止请求 |
| `rate_limited` | 站点明确提示访问频繁 | 停止请求 |

安全验证只能由用户手动完成。程序不破解、不自动刷新、不切换代理。同一批次最多允许三次人工处理后恢复；仍未完成时返回 `partial` 或 `challenge_detected`。

断点文件只允许保存查询摘要、批次编号、完成标记和必要题录，不得包含账号、Cookie、HTML、完整 URL、完整浏览器状态或本机绝对路径。对外警告只返回简短分类信息。

## 10. 自动化测试

### 10.1 通用版回归测试

- 默认生产入口在设置 `CNKI_WEBVPN_HOME` 后能够创建专业检索运行时。
- 正常构造 `CnkiMcpServer()` 后，只替换浏览器边界即可完成离线工具调用。
- `chinese_top_journals` 使用精确期刊表达式。
- `cssci` 使用主题表达式和 CSSCI 来源类别。
- 页面驱动设置每页 50 条，并在重新渲染后解析结果。
- 登录超时、窗口关闭、任务取消和服务关闭均释放资源。
- `no_results` 与 `no_data_retry_later` 的真值表互不混淆。
- 公开主题检索的按钮候选和提交后状态分类继续通过回归测试。

### 10.2 环境版测试

- MCP schema 同时包含 `cnki_search_env` 和 `cnki_professional_search_env`。
- 两个专业分组的表达式、来源类别和目录范围正确。
- 241 种环境 CSSCI 期刊在长度限制下动态分批，没有遗漏和重复。
- 通用版与环境版的服务名、工具名和环境变量互不冲突。
- 环境版十级目录、各等级数量和期刊判级行为保持不变。

### 10.3 通用质量门槛

两个版本均执行：

- ruff；
- mypy；
- 全量 pytest；
- 目录校验；
- MCP schema 和 stdio 握手；
- Skill 与 MCPB 两种布局的离线工具调用；
- 安装器隔离 HOME 测试；
- 连续两次发布构建与内容检查。

CI 不访问知网，不使用真实 WebVPN 账号。Ubuntu 测试 Python 3.11、3.12、3.13、3.14；Windows 和 macOS 至少测试 Python 3.11。正式发布产物固定由 Ubuntu Python 3.11 构建。

## 11. 人工 WebVPN 端到端验证

发布前在 Windows 可见浏览器中依次完成：

1. 通用版 `chinese_top_journals`；
2. 通用版 `cssci`；
3. 环境版 `chinese_environment_top`；
4. 环境版 `environment_cssci`。

每项均核验：

- WebVPN 登录后从知网首页进入高级检索并切换到专业检索；
- 表达式完整，未被输入框截断；
- 来源类别按分组规则设置；
- 每页显示数量成功设为 50；
- 成功时题录含篇名、期刊和发表年度，并完成期刊判级；
- 无结果、临时无数据、页面变化和安全验证能够正确分类；
- 执行结束后没有保存 Cookie、HTML、完整 URL 或浏览器状态。

如果任一产品不能完成真实端到端验证，该产品不得创建正式标签和 Release，也不得声称已支持生产使用。
