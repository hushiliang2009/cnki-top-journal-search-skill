# 无环境 Skill 的独立基线

测试日期：2026-07-26

测试场景：

- PFAS 水处理与污染控制；
- 气候变化适应与环境政策；
- 中国城市空气污染治理；
- 环境健康与暴露科学；
- 公司金融与董事会治理。

环境主题场景均未使用《环境科学与工程学科顶尖期刊目录 v3.0》，而是自行采用
JCR 分区、学科百分位或经验性 S/A/B/C 等级。基线因此无法返回十级目录层级、
环境细分领域、正式证据、来源目录和 NCS 内部顺序，也不能证明附录记录未进入
主索引。

公司金融与董事会治理场景正确判断为非环境主题，并建议使用通用顶级期刊检索
能力。该结果作为环境 Skill 不应误触发的对照。
